美术审美

"金色小球在深蓝底色上的最强明度对比，视线自动追踪"

01

🌈 配色体系：信号灯到奢侈品的渐变

深色基底 #0b1220 在 OLED 屏上几乎不发光，天然省电且对比度极高。 墙面 #2b436e 与通道 #0e1830 形成冷暖微差， 不靠描边就划分出功能区。五档中奖色遵循 绿(安全) → 蓝(提示) → 红(警戒) → 紫(稀有) → 金(巅峰) 的渐变逻辑，玩家无需读数字，凭颜色即知档次。

02

📐 6 级字体体系，Hero 独立于缩放

Hero 48sp 按屏宽占比设计，桌面 density=1 正常，手机 density=2.5~3 也只有它不被缩成蚂蚁字； Key 19sp 余额数字醒目；Act 16sp 操作按钮；Body 14-15sp 标签统计； Aux 13sp 状态指示；Scene 20 逻辑 px 槽位倍率跟画布等比缩放。 UI 用 sp、场景用 px，两套体系各司其职不混淆。

03

✨ 三段式动画节奏

中奖特效是精心编排的三段式：槽位白闪 0.3s 先行定位 → Hero 大字 2.4s 缩放弹性 (1.0→1.2→1.0) + 上浮 38px/s + 透明度淡出 → 落袋浮字 补充确认。阴影层独立于主体，形成"浮出屏幕"的视差感。 toast 余额不足用前 60% 实色后 40% 淡出，阅读时间足够又不滞留。

04

📱 双因子缩放：纵横独立自适应

_ui_scale = min(1.0, height/680dp) 纵轴主导，行高/按钮宽/间距等比缩； _font_scale = min(1.0, width/360dp) 横轴辅助，窄屏时字体不溢出。 纵向边距用 u2 平方衰减，横屏时激进挤掉空白，把垂直空间全还给游戏区。 宽屏内容居中、两侧深色边——不追求填满屏幕，而是填满注意力。

05

💫 三个最精妙的设计细节

🔴 程序化径向渐变小球

7 段色阶 (亮黄芯 → 深褐边) + 97% 处边缘抗锯齿，64×64 RGBA 纯 Python 零依赖。 Kivy Texture linear 过滤让放大后依然圆润。不受分辨率限制且包体零增量。

🎲 槽位底色深浅两套

x20 金字用深色底 #0b1220 替代白色，金色在白底上对比度不足， 一个特判就解决了可读性问题，代码量才一行。

🔉 三态声音按钮的色彩语义

绿底深字 (语音) / 蓝底白字 (纯音效) / 深底灰字 (静音)，三种色相完全不同，余光一扫即知当前模式。 用颜色做状态指示器的手法贯穿全界面。

🧩

程序架构

"结果确定、过程真实，两者互不污染"

01

🎯 作弊预定 + 物理表演双层架构

核心是"结果预定 + 表演分离"。choose_target() 发射前按概率选定目标槽位， 确保 RTP 精确可控；steer_ball() 引导球体时只注入 vx 不改位置， 物理引擎依旧是纯函数 physics_step() 无副作用。 这比传统"调倍率 → 赌大数定律"方案收敛速度快一个数量级。

02

🎵 程序化音效合成：零文件、零延迟

36 个音效由正弦分音 + 噪声瞬态 + 梳状混响实时合成，总耗时仅 ~370ms。 _ARNG 独立随机流与游戏主随机流物理隔离——改音效配方不会扰动盘面和落点序列。 可复现、无版本管理负担、无加载延迟。

03

🔊 跨平台音频后端三级降级

SoundPool (Android, pyjnius) → _WaveOut (Windows, winmm, 8 声道可叠加) → _KivySoundOut (兜底) → 静音。每层接口统一 (gain / 节流 / impact 同构)， 任意层缺失时自动跌落，保证游戏在任何平台都有声或有体面静音，业务代码只写一次。

04

🛠 卡死兜底：看位移不看速度

steer_ball() 每帧注入 vx，碰撞事件在死锁位置仍在产生—— 速度和事件位都在"说谎"。只有帧间位移 ≤ 1px 不撒谎：球的位置被钉阵物理锁定不动。 判据从"发射后 8 秒"改为"连续 4 秒位移 ≤ 1px"，杜绝提前结算。

05

🔧 构建管线分离 + 更多工程亮点

📦 生成物架构

main.py 由父项目 build_android_main.py 自动生成——物理/音效从 tkinter 源文件原样抽取， Kivy UI 手写段拼接。单一事实源，杜绝两版漂移。

🗣 语音数字朗读

42 个 edge-tts 预录词条，中文数字按"二/两"规则 (千位/万位自动选词) 映射为语音名列表， 队列 5ms 间隔播放，与合成音效走同一 Sfx 总线。

"这本质上是老虎机的数学内核套了一层弹珠机的皮，两者各自做到极致。 物理表演骗过了直觉，数值控制骗过了概率。" — 设计专家评审
🎮

游戏设计

"糖多盐少的配方：小甜头频繁，大高潮稀有但真实存在"

01

🎲 老虎机内核 + 弹珠机外皮

传统弹珠机的 RTP 依赖物理模拟收敛，误差大且不可控。本作发射前就选定了 target_slot，物理引擎只负责生成可信的视觉轨迹。 玩家看到的每颗球都是"真的在弹"——物理表演骗过了直觉，数值控制骗过了概率。 RTP 精确到 ±0.05，两者各自做到极致。

02

💪 蓄力机制：67px 的操作感与零成本容错

从弱蓄力到满蓄力，球的冲顶横坐标从 336 跨到 269，67px 的跨度保证玩家能感知到自己"用力"的差异 (>50px 阈值)。哑火 (P<0.15) 球弹不上去掉回柱塞，不扣珠、不计局、不换盘面—— 避免误触扣珠的挫败感、免费刷盘面的漏洞、和新手练习的心理负担。

03

📊 倍率分布：高频小奖养节奏，低频大奖拉期待

E=3.35 的期望值设计极聪明：x2 占 55% 保证"几乎每把都有东西回去"的正反馈密度； x20 仅 1.5% 制造稀缺感和社交传播素材。 玩家不会因连续空转而弃游，也不会因大奖泛滥而麻木。

04

📈 防沉迷的心理账户包装

"每轮 20/50/100 次"不是冷冰冰的限制，而是包装成"完成一轮挑战"的闭环。 切换轮数自动重置计数——玩家不会觉得自己被系统踢出去，而是"这轮打完了，换一轮"。 这是行为经济学里"心理账户"的经典应用：把限制变成目标，把终点变成成就感。

05

🎉 更多设计亮点

🔉 声音三态循环

语音 → 音效 → 静音，不是简单的开/关。每一步切换都有专门的提示音确认，操作反馈闭环完整。 默认语音已开，降低静音启动后的"空窗感"。

📳 震动时长分档

45/75/110/150ms 逐级递增——玩家闭眼也能感知中奖大小。振幅 255 (满幅) 而非系统默认的 ~50%， 触觉反馈的层次化设计。

🛡 哑火双保险

不扣珠 + 不换盘面，双保险防止两种独立漏洞——"误触惩罚"和"免费刷盘"， 深刻理解老虎机类游戏最致命的两个用户体验死穴。

"三通道从未同时缺席——任何时候玩家至少有两个感官参与。 音效是时间叙事线，视觉是空间信息层，触觉是情感放大器。" — UX 专家评审
🧠

用户体验

"哑火球保留完整的'差点就出去了'戏剧感，但零损失"

01

🎧 三通道反馈体系：一条完整的时间叙事线

棘轮声随蓄力递增 (间隔 250ms → 70ms) 建立期待 → 满蓄力"咔哒"闭合 → 发射弹簧声 → 顶部碰撞"铛" (空中锚点) → 撞钉网格质感 → 入袋上滑音效 → 落袋声收束 → 中奖琶音或语音播报闭环。 视觉 + 听觉 + 触觉三通道从未同时缺席。

02

🛡 容错设计：最克制的善意

哑火：力度不足 0.15 阈值，球弹出去但掉回柱塞，不扣珠子、不换盘面、不计局数。 不会因"手滑"受罚，也刷不了盘面。余额不足：中央 toast + 语音播报全句 + 2.9s 节流防连点叠弹。 卡死兜底：看位移不看时间，避免球晃动未落袋时提前结算。

03

♿ 无障碍与可访问性

语音播报替代琶音是深思熟虑的选择：手机外放低频响应极差，琶音听感模糊， 人声在中频段则清晰可辨。默认模式即为"语音已开"。 字体层级刻意分层：UI 用 sp 跟随系统，场景内用逻辑 px 跟盘面缩放， Hero 大字按屏宽占比独立，互不干扰。

04

👍 单手操作与屏幕适配

全竖屏布局，蓄力按钮位于底部拇指热区。双因子自适应 (_font_scale 宽缩放 + _ui_scale 高缩放) 独立计算： 窄屏缩字、矮屏 (横屏) 缩 UI 还游戏区垂直空间。 宽屏内容居中、两侧深色边——不追求填满屏幕，而是填满注意力。

05

💙 最打动人心的 UX 细节

🎬 哑火保留表演，零损失

球弹起、落回柱塞——完整的"差点就出去了"戏剧感，但零损失。 惩罚感被替换为"下一次"的参与感。

⏱ 130ms 呼吸空白

结果音头部烘了 130ms 前置静音，等落袋声落地。 让"咚"和"珠子加五十"之间有呼吸，而不是叠在一起抢耳。

🛋 切静音可反悔

"关闭声音"语音播完才真静音，延迟 1s；窗口内切回则取消。 给了足够时间反悔，没有"按下去就掉进黑洞"的焦虑。

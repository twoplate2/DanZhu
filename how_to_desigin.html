一句话总结：这个游戏厉害在哪

🔌 看得见的蓄力 — 弹簧可视化

地板下方暗色凹槽内，一条 Z 字形弹簧（上横→斜线→下横）随你按压力度实时压缩。线宽 1.5px，跨度 32px，颜色从灰蓝渐变至金黄——蓄力不再是抽象的数字，而是肉眼可见的物理过程。释放后 0.5 秒平滑回弹。

🗣 听得见的数字 — 43 个 AI 语音

中奖时念出"珠子加五十"，余额不足时提醒你重置，轮次结束时完整播报"本轮游戏 50 次已结束，剩余 1250 个珠子，欢迎你再次挑战"。22 个独立数字朗读片段按中文规则拼接（二千→两千），对标计算器项目的预录制方案。

🎰 老虎机的内核 — RTP 精确 120%

发射前就通过 choose_target() 选定了落点槽位，物理过程只是表演。80% / 100% / 120% 三档可选，RTP 精度控制在 ±0.05。玩家看到的是弹珠碰撞，幕后是精确的概率引擎。

🚧 玩得有度 — 防沉迷机制

每轮最多玩 20 / 50 / 100 次（可设定），达到上限后弹窗 + 语音播报 + 自动重置。轮次历史存到本地 JSON，最近 100 条重启不丢失。不是惩罚，而是"恭喜你完成了一轮挑战"的游戏化包装。

📐 像素级排版 — 四行对齐 24dp

返还率、投注、珠子数量、重置按钮——四行文字左沿精确对齐 24dp，行间距统一 5dp。双因子缩放自适应横屏窄屏，手机竖屏、平板、桌面宽屏——排版从来不会崩。

美术审美 — 在 520×660 的竖井里画出整个世界

🎨 深色 OLED 友好配色

底色 #0b1220 纯黑偏蓝，面板 #15223c 深蓝灰。五档中奖颜色（绿蓝红紫金）在高对比度深色背景上鲜艳但不刺眼，手机上 OLED 屏幕更省电。

📐 6 级字体体系

Hero 48sp（中奖大字）→ Key 18sp（标题）→ Act 16sp（按钮）→ Body 14sp（正文）→ Aux 13sp（辅助）→ 场景 20px（槽位倍率）。sp 和逻辑 px 两套体系互不干扰，中奖大字按屏宽占比设计，不跟场景缩放。

✨ 三段式动画节奏

中奖大字：0-0.3s 缩放 1.0→1.2（爆发感）→ 0.3-1.0s 保持 → 1.0-2.4s 淡出。槽位白闪 0.3s + 落袋浮字 + 指示灯变色，三个层次同时发生但不打架。

📱 双因子自适应缩放

_font_scale（宽度驱动，窄屏缩小字体）+ _ui_scale（高度驱动，横屏缩小 UI）。竖屏两因子均为 1.0，横屏时自动把行高/间距/字号等比缩小，把垂直空间还给游戏区。

程序架构 — 生成物管线 + 双层引擎 + 0 音频文件

🎯 作弊预定 + 物理表演

choose_target() 发射前选定目标槽位，RTP 精确至 ±0.05。物理层 steer_ball() 只改 vx 不改位置，引导球飞到预定槽——玩家看到的是真实的碰撞和弹跳，幕后是精确的概率控制。

🎵 36 个程序化音效，0 音频文件

正弦分音 + 噪声瞬态 + 梳状混响，全部在 bake_bank() 中实时合成。_ARNG 独立随机流与游戏逻辑完全隔离。Android 用 SoundPool 硬件 mixer，Windows 用 winmm 8 声道叠加。

📦 main.py 是生成物

build_android_main.py 从 PC 版 plinko.py 原样抽取物理/音效/自测段，拼接手写 Kivy UI 段。单一事实源，杜绝两版漂移。

🔌 弹簧：纯 Line 原语，零图片

3 条 Kivy Line（上横→斜线→下横）构成 Z 字形弹簧。宽度 1.5px，跨度 32px（边距 5）。颜色 RGB 线性插值灰蓝→金黄。释放后 _spring_power 0.5s 衰减平滑回弹。完全用代码"画"出来的弹簧。

"一个弹珠机游戏，弹簧居然是用代码一行一行画出来的——而且比图片还好看。"
游戏设计 — RTP 120% 的正期望博弈

🎰 老虎机的内核，弹珠机的外表

发射前选落点 → RTP 精确控制（80% / 100% / 120%）。盘面只是展示，真实赔付由 choose_target 决定。这意味着可以大胆调高 RTP 到 120%——玩家能感受到"高返还"的快感，而数值完全可控。

💪 蓄力机制：67px 的操作感

弱蓄力冲顶 x=336，满蓄力 x=269，跨度 67px（≥50 玩家可感知）。力度 < 0.15 触发哑火：球弹出去但掉回柱塞，不扣珠不计局——新手零成本试错。

📊 倍率分布：高频小奖养节奏

x2(55%) x3(25%) x5(13%) x10(5.5%) x20(1.5%)，E=3.35。x10+ 大奖滚分 1.2s + 停留 0.7s，x2 起震动分档（45/75/110/150ms）——闭眼也能感知中奖大小。

🚧 防沉迷的游戏化包装

每轮 20/50/100 次可选，达上限弹窗"本轮游戏 X 次已结束"并语音播报，自动重置无需手动操作。轮次设定弹窗纵向自适应防溢出，ScrollView 可滚动 100 条历史。

用户体验 — 看得见、听得见、感得到

🔊 三通道反馈闭环

视觉：力度条 + 弹簧压缩 + 中奖大字 + 槽位白闪
听觉：36 合成音效 + 43 语音播报 + 蓄力棘轮递增
触觉：x2 起震动 45-150ms 分档 + 发射按钮深棕变色
三种通道同时工作，玩家闭眼也知道发生了什么。

🛡 容错设计全程覆盖

哑火不扣珠（力度不足的球弹回柱塞）、余额不足 toast + 语音提示（2.9s 节流防叠）、卡死兜底看位移不看速度（位移≤1px/帧超 4s 强制定位）——三套安全网确保玩家不会被 bug 惩罚。

👍 单手操作 + 状态锁定

所有按钮在拇指热区，飞行期间语音按钮和轮次按钮同步灰化（disabled），防止操作时序冲突。重置按钮强制中断任何状态，on_press 闪亮 + 28sp toast + 语音三重确认。

💙 最打动人心的 UX 细节

满蓄力时弹簧压成一条金线 + charge_full 音效——听到这声就知道可以松手了。发射按钮充电时从红色渐变为深棕色（#8B6914），手感通过视觉暗示传递。

小游戏也可以有大设计

设计是为"感知"服务的

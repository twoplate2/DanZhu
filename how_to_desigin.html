弹簧可视化：从"盲猜"到"看见"

纯 Kivy Line 原语实现，零图片依赖，4 个状态 + 3 种颜色

01

📏 Z 字形结构：上横 → 斜线 → 下横

三条 Line 原语构成完整的 Z 字形弹簧。线宽 1.5px，端点 round 圆头，水平跨度 32px（边距 5）。蓄力时两条横线间距从 9px（松弛）压缩至 23px（满蓄力），对角线同步收窄——视觉上的弹簧压缩感完全由数学驱动，每帧重新计算 6 个端点坐标。

02

🎨 颜色叙事：灰蓝 → 金黄 → 橙红

松弛（力度 0）：#8fa0c4 蓝灰，安静的待命状态。
蓄力中（0.15~1.0）：RGB 三通道线性插值，从灰蓝平滑过渡到 #f0b000 金黄——越来越"烫"，紧迫感递增。
哑火（< 0.15）：#c45a4a 橙红，警告"这一发弹不上去"。

03

⏱ 释放回弹：0.5 秒平滑衰减

松手后弹簧不是瞬间跳回——_spring_power 以每帧 FIXED_DT/0.5 速率线性衰减，0.5 秒内从压缩态平滑伸展回原位。蓄力时弹簧即刻跟随（无延迟）、释放时减速回弹（有惯性），一快一慢的节奏完全符合物理直觉。用最简单的一次函数，做出了最自然的"弹簧感"。

04

🎭 暗色凹槽：弹簧的专属舞台

弹簧嵌在 #060e18 深色凹槽里，精确开在竖井正下方（x: 466~508），宽度与发射通道完全对齐。深底色把弹簧的亮色衬得更醒目。凹槽本身暗示"这里有东西在动"——即使玩家不知道这叫 Z 字形弹簧，也能在看一眼后理解"它在变，它在告诉我力量"。

💡

为什么弹簧可视化是一个"大设计"？

弹珠机类游戏的蓄力机制一直有一个体验断层：玩家按住按钮，但只能靠力度条的数字来估算力度。力度条是"仪表盘思维"——你读取数据，然后行动。弹簧是"物理世界思维"——你看见弹簧被压缩，本能就知道"这就是弹射的力量"。后者不需要学习、不需要识字、不需要注意力切换——它是前文字时代就刻在人类大脑里的力学直觉。

而且弹簧做在地板下面不是随意的：它是发射通道的垂直延伸——球从竖井弹上去，弹簧在竖井正下方压缩——上下呼应，形成一条完整的"力量轴线"。这是 UI 设计里难得的"装饰即功能"案例：它既是装饰，又是信息，又是空间锚点。

🎨

美术审美

"金色小球在深蓝底色上的最强明度对比，视线自动追踪"

01

🌈 配色体系：信号灯到奢侈品的渐变

深色基底 #0b1220 在 OLED 上几乎不发光，天然省电且对比度极高。五档中奖色遵循 绿(安全) → 蓝(提示) → 红(警戒) → 紫(稀有) → 金(巅峰) 的渐变逻辑。槽位底色备有两套：x20 金字用深色底替代白色，一行代码解决金色在白底上的对比度问题。

02

📐 排版精度：24dp 左沿 + 5dp 行间距

返还/投入/信息/底行四行文字首字符统一左沿 24dp，行内 spacing 5dp。每行按钮宽度固定，标签右对齐 115dp——这不是"差不多对齐就行"，而是精确到像素的网格系统。双因子缩放（_font_scale + _ui_scale）在横屏时激进挤掉空白，纵向边距用 u2 平方衰减，把垂直空间全还给游戏区。

03

🎬 三段式动画节奏

中奖特效三段编排：槽位白闪 0.3s 先行定位 → Hero 大字 2.4s 缩放弹性 (1.0→1.2→1.0) + 上浮 38px/s + 透明度淡出 → 落袋浮字 补充确认。阴影层独立于主体，形成"浮出屏幕"的视差感。toast 余额不足前 60% 实色后 40% 淡出，阅读时间足够又不滞留。

04

🔹 发射按钮的颜色叙事

按钮不只是功能入口——它的颜色在讲故事：充电态：深棕 #8B6914，暗示"正在蓄积力量"； 哑火区间（P < 0.15）：红色警告，提醒"力度还不够"； 力度条：金黄从下往上填充，与弹簧的金黄渐变上下呼应。三种颜色一套叙事：棕（准备）→ 金（蓄力）→ 红（危险）。

🧩

程序架构

"结果预定、过程真实，两者互不污染"

01

🎯 作弊预定 + 物理表演双层架构

choose_target() 发射前按概率选定目标槽位，RTP 精确到 ±0.05。 steer_ball() 引导球体时只注入 vx 不改位置，物理引擎依旧是纯函数 physics_step()。80/100/120 三档一键切换，比传统"调倍率赌大数定律"收敛速度快一个数量级。

02

🎵 程序化音效：370ms 合成 36 个音效

正弦分音 + 噪声瞬态 + 梳状混响，36 个 16bit PCM 音效在 bake_bank() 中实时合成，总耗时仅 ~370ms。_ARNG 独立随机流与游戏主随机流物理隔离——改音效配方不会扰动盘面和落点序列。0 音频文件、0 版本管理负担、0 加载延迟。

03

🔊 跨平台音频三级降级

SoundPool（Android 硬件 mixer, pyjnius）→ _WaveOut（Windows winmm, 8 声道叠加）→ _KivySoundOut（兜底）→ 静音。每层接口统一（gain/节流/impact 同构），任意层缺失自动跌落。语音文件两种播放路径（named 直读 / pcm 剥头并入音效库）完全同构，业务代码只写一次。

04

🛠 卡死兜底：看位移不看速度

steer_ball() 每帧注入 vx，碰撞事件在死锁位置仍在产生——速度和事件位都在"说谎"。只有帧间位移 ≤ 1px 不撒谎：球的位置被钉阵物理锁定。判据从"发射后 8 秒"改为"连续 4 秒位移 ≤ 1px"，杜绝晃动未落袋时提前结算（音效/飘字/震动全早于真实落袋）。

05

🔧 构建管线与数字朗读系统

📦 生成物架构

main.py 由父项目 build_android_main.py 自动生成——物理/音效从 tkinter 源原样抽取，Kivy UI 手写段拼接。单一事实源，杜绝两版漂移。

🔢 数字朗读：22 片段 · 5ms 队列

0~9 / 十百千万 / 两，共 22 个独立语音片段。中文数字按"二/两"规则（千位/万位自动选"两"）映射为 clip key 序列，按 duration+5ms 间隔排队播放——对标 Clac 项目方案，不拼接 PCM，保持 Xiaoxiao 原声音质。

"这本质上是老虎机的数学内核套了一层弹珠机的皮，两者各自做到极致。 物理表演骗过了直觉，数值控制骗过了概率。" — 设计专家评审
🎮

游戏设计

"糖多盐少的配方：小甜头频繁，大高潮稀有但真实存在"

01

💰 RTP 120%：三档可切的精确返奖

80% / 100% / 120% 三档一键切换，精度 ±0.05。 不是"调倍率赌大数定律慢慢收敛"——发射前 choose_target() 就按概率表选定了目标槽，物理引擎只负责生成可信的视觉轨迹。 玩家看到的每颗球都是"真的在弹"，但落点在发射瞬间就已确定。

02

🚧 防沉迷轮次：限制包装成成就感

每轮 20 / 50 / 100 次可选（默认 50），达上限弹出总结窗口，语音播报完整句子后自动重置。 JSON 持久化保存最近 100 条历史记录。这不是冷冰冰的"你被踢了"——而是包装成 "完成一轮挑战"的闭环。轮次设定弹窗纵向自适应 + ScrollView 可滚动——不溢出、不截断。

03

💪 蓄力机制：67px 操作感 + 零成本容错

弱蓄力冲顶 x=336，满蓄力 x=269，67px 的跨度保证玩家能感知到"用力"的差异（≥50px 阈值）。 哑火（P < 0.15）球弹起落回柱塞，不扣珠、不计局、不换盘面——三条防线各管各的： 防误触扣珠的挫败感、防免费刷盘面的漏洞、防新手练习的心理负担。

04

📊 倍率分布：E=3.35 的甜区设计

x2 占 55% 保证"几乎每把都有东西回去"的正反馈密度； x20 仅 1.5% 制造稀缺感和社交传播素材。玩家不会因连续空转而弃游，也不会因大奖泛滥而麻木。 这是行为经济学里"可变比率强化"的经典配方——最高成瘾性的奖励频率。

05

🎉 更多设计亮点

🔉 三态声音开关

语音已开(绿底) → 音效已开(蓝底) → 音效已关(深底)，三种色相完全不同，余光一扫即知当前模式。每次切换都有专属提示音确认。

📳 震动时长分档

45/75/110/150ms 逐级递增——闭眼也能感知中奖大小。振幅 255（满幅）而非系统默认 ~50%，触觉反馈层次化。

🚫 飞行状态锁定

球在飞行中时，语音按钮和轮次按钮同步灰化——防止中途切换设置导致状态混乱，同时提供清晰的不可操作视觉暗示。

"三通道从未同时缺席——任何时候玩家至少有两个感官参与。 音效是时间叙事线，视觉是空间信息层，触觉是情感放大器。" — UX 专家评审
🧠

用户体验

"每一步操作都有确认，每个状态都有声音，每一处沉默都是设计"

01

🗣 43 个语音场景：手机静音时代的"听觉 UI"

15 种中奖金额全覆盖（"珠子加五十"）、余额不足全句播报（2.9s 节流防连点叠弹）、 轮次结束队列拼接（结束提示 + 数字朗读 + 后缀，5ms 间隔）、 切换轮次 / 手动重置 / 声音切换各有专用语音。 全部 XiaoxiaoNeural +10% 语速预录，人声在手机中频段清晰可辨——即使琶音被外放吃掉，语音依然通透。

02

🛡 容错三件套：哑火 · 余额不足 · 卡死

哑火：力度不足 0.15 阈值，球弹起落回柱塞——完整的"差点就出去了"戏剧感，但零损失。 余额不足：中央 toast + 语音播报全句，2.9s 节流防连点叠弹。三档提醒同时触发（toast + 语音 + 按钮状态不变）。 卡死兜底：看位移不看时间，避免球晃动未落袋时提前结算。

03

🔄 重置按钮：强制中断任何状态的"逃生舱"

on_press 瞬间闪亮反馈，强制中断任何状态（ready / charging / flying / landing / landed）， 28sp toast "珠子数量已重置" + 语音播报 voice_reset_progress。 无论在蓄力、飞行还是等结果，按下就重置——不是"等这轮结束后再重置"，而是"现在就重置"。 这是给玩家的终极控制权。

04

🎧 三通道反馈：一条完整的时间叙事线

棘轮声递增（间隔 250ms → 70ms）建立期待 → 满蓄力"咔哒"闭合 → 发射弹簧声 → 顶部碰撞"铛"（空中锚点）→ 撞钉网格质感 → 入袋上滑音效 → 落袋声收束 → 中奖琶音 / 语音播报闭环。 每一步都有听觉锚点。视觉 + 听觉 + 触觉三通道从未同时缺席——任何时候玩家至少有两个感官参与。

05

💙 最打动人心的 UX 细节

🛋 切静音可反悔

"关闭声音"语音播完才真静音，延迟 1s；窗口内切回则取消关闭——没有"按下去就掉进黑洞"的焦虑。

⏱ 130ms 呼吸空白

结果音头部烘 130ms 前置静音，等落袋声落地。让"咚"和"珠子加五十"之间有呼吸，不叠在一起抢耳。

👍 单手操作优先

全竖屏布局，蓄力按钮位于底部拇指热区。双因子自适应：窄屏缩字、矮屏缩 UI 还游戏区垂直空间。宽屏不追求填满，而是填满注意力。
